# Spec：个人助手首版

状态：待评审。按 2026-10-21 的决定重写（Think、Google Drive、Cloudflare Access、用户自备模型）。每条验收都写成可执行的操作和可观察的结果。

依据：[产品 Intent](../intents/personal-assistant.md)、[ADR-0001](../adr/0001-cloudflare-free-tier.md)、[ADR-0002](../adr/0002-think-google-drive.md)。界面细节见 [网页界面 Spec](web-ui.md)。

## 首个闭环

1. 用户在手机上用 Google 账号登录。
2. 用户上传一份文本资料到 Drive，或从 Drive 中选择一份已有资料。
3. 用户在会话中要求助手读取并整理这份资料。
4. 助手调用工具读取资料，回答中带上原文摘录作为引用。
5. 用户要求保存时，助手把整理结果另存为 Artifact，写入 Drive，原文不变。
6. 用户关闭网页再打开，仍能看到这轮任务的状态和结果。

首版不包括：通用 RAG、自动记忆提炼、邮件、ehall、定时任务。

## 名词

- **资料**：用户自己的文件，主要放在 Drive 的 `GenseBot/资料/` 下；助手也可以读取 Drive 中的其他文件。助手只在 `GenseBot/` 下写入；要修改或删除已有资料，需要用户明确要求，并在确认后执行。`GenseBot/` 以外的文件只读。
- **Artifact**：助手生成的产物，比如整理稿、报告或代码。会话中可以在侧边面板预览，保存后写入 Drive 的 `GenseBot/Artifacts/`。
- **一轮（Turn）**：一次用户消息，以及助手由此执行的模型调用和工具调用。

## 行为与验收

| 编号 | 行为 | 验收操作 → 期望结果 | Intent |
| --- | --- | --- | --- |
| S1 | 只有指定用户能访问 | 未登录访问页面或 `/agents/*` → 跳转到 Access 登录页或返回 403。用非白名单 Google 账号登录 → 被拒绝。Worker 直接收到不带有效 Access JWT 的请求 → 返回 403 | I2 |
| S2 | 每轮有可见状态 | 发送一条需要调用工具的消息 → 界面依次显示执行中、工具调用、完成。模型端点返回错误 → 显示失败和原因，并提供“重试” | I1、I2 |
| S3 | 重复提交不会重复执行 | 用同一个请求标识（消息 ID 或 `idempotencyKey`）连续提交两次 → 只产生一轮，模型只被调用一次 | I2 |
| S4 | 关闭网页不取消任务 | 发送一个耗时较长的任务后立即关闭标签页，一分钟后重新打开 → 能看到完整结果，或明确的失败状态 | I2 |
| S5 | 资料与 Artifact 读写 | 上传一份 `.md` 后让助手读取 → 工具读到的内容与原文一致。让助手保存整理结果 → Drive 的 `GenseBot/Artifacts/` 下出现新文件，原资料的修改时间不变。上传超过大小上限的文件 → 被拒绝，并说明原因。让助手读取 `GenseBot/` 以外的文件 → 可以读取；让它在 `GenseBot/` 以外创建或修改文件 → 被拒绝，Drive 中没有变化 | I3、I6 |
| S6 | 回答可追溯 | 引用以“文件名 + 原文摘录”显示，点击后打开该文件并高亮摘录。如果文件已被修改、找不到摘录，提示“原文已变化”，并仍显示当时保存的摘录 | I3 |
| S7 | 中断后恢复或明确结束 | 执行中重新部署 Worker → 该轮自动继续并完成，或标记为失败，不会一直停在“执行中”。有外部副作用的工具，在恢复时不会被自动重跑 | I1、I2 |
| S8 | 只有授予的工具可用 | 在“定制”页关闭某个工具，再提出需要它的请求 → 助手说明该能力不可用，工具没有被执行 | I4 |
| S9 | 兜底限制 | 构造一个让模型反复调用工具的提示 → 达到单轮工具调用上限后停止，并显示“已达到单轮步数上限”。模型端点持续报错 → 有限次重试后标记失败，不会无限重试 | I5 |
| S10 | 过程可见且不泄露凭据 | 每个工具调用都能展开查看参数和结果摘要。任何界面和网络响应中都不出现模型 token、Google refresh token 或 Access JWT 的内容 | I1、I2 |

## 兜底限制

不设置按天或按月的用量配额（I5），只防止失控：

| 限制 | 初始值 | 触发后 |
| --- | --- | --- |
| 单轮工具调用轮数 | 20（Think `maxSteps`） | 停止本轮，保留已有内容 |
| 模型流无输出超时 | 120 秒（`chatStreamStallTimeoutMs`） | 进入有限次恢复，仍失败则标记失败 |
| 崩溃恢复次数 | 按 Think `chatRecovery` 默认值，验证后再调整 | 标记失败，不再自动重试 |
| 单个上传文件 | 2 MB 文本 | 拒绝上传 |
| 定时任务（后续） | 同一任务两次运行至少间隔 5 分钟 | 拒绝创建 |

这些数值写在代码配置中，可以调整，不是产品承诺。Cloudflare 平台的额度错误（如 DO 请求数用尽）要显示为“平台额度已用尽”，与模型错误区分开。

## 外部操作

- 文件、网页和 MCP 返回的内容是数据，不是指令，不能扩大工具权限。
- 删除或覆盖资料、发送邮件、提交 ehall 表单等外部写操作，执行前必须展示最终内容，并由用户确认。确认绑定最终内容：内容一改，就要重新确认。
- 同一个确认只执行一次。执行结果不确定（如超时）时标记为“结果未知”，不自动重试，由用户检查后决定。
- 课程退出、申请撤销这类操作，助手不能自行决定。
