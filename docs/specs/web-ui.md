# Spec：网页界面

状态：2026-11-10 按 [roadmap-5](../plans/roadmap-5.md) 重写，描述 `packages/web` 的当前实现。此前的 M0 草案（项目、资料页、Google Drive、记忆、hash 路由）已全部作废。

网页是单个所有者的工作台：对话、给助手接工具（插件、MCP、Skills）、自动化和飞书渠道。它只通过 `@gense/protocol` 和服务器通信：一条 WebSocket（`/ws`）承载全部状态和请求，登录和改密码走 `/api/*`。

## 信息架构

| 路径 | 页面 | 内容 |
|---|---|---|
| `/` | 首页 | 按时段问候、输入框、建议词；发送后创建对话并跳转 |
| `/c/:treeId` | 对话 | 轮次、分支、工具步骤、界面（生成式 UI / MCP Apps / Artifact）、工作区文件 |
| `/plugins`、`/plugins/skills` | 插件与 Skill | 内置插件、MCP 服务器；Agent Skills 的安装、开关和查看 |
| `/automations` | 自动化 | 定时任务、Webhook |
| `/channels` | 渠道 | 飞书连接设置、配对、允许名单、最近收到的消息 |
| `/settings/:section` | 设置 | 个性化、模型、外观、账户 |

- 路径路由；服务器对未知路径返回 `index.html`，刷新或分享链接停在原处。
- 侧栏：新对话、搜索（`⌘K` / `Ctrl+K` 命令面板）、三个页面入口、置顶和按日期分组的对话、设置。手机上是抽屉。
- 未登录时只显示密码登录页；会话失效（例如在别处改了密码）时回到登录页。

## 对话页

- **轮次**：用户消息靠右，可编辑（产生新分支）和复制；回答靠左，可复制、重新生成、从这里分叉。同一位置有多个版本时显示 `‹ 2/3 ›` 切换。
- **步骤**：思考和工具调用折叠成一行摘要（“3 次工具调用 · 1 次失败”），展开看参数和结果。带界面的工具结果直接显示在正文里。
- **界面**：生成式 UI（`ui_render`，OpenUI 程序）、Artifact 卡片和 MCP Apps 都渲染在同一个槽位。MCP Apps 运行在只允许脚本和表单的沙箱 iframe 中，带注入的 CSP，通过 postMessage 上的 JSON-RPC 和宿主通信；可以展开到右侧面板（手机上全屏）。
- **流式**：只有读者停在底部时才跟随新内容；上滚后停止跟随并出现“回到底部”。
- **分支**：顶栏的分支图显示整棵树；处在支线时有横幅，可以“总结给主线”或返回主线。
- **输入框**：附件（单个不超过 20 MB）、`/` 指定 Skill 或命令、`@` 引用文件、模型和推理强度选择、发送 / 停止。模型选择按浏览器记住。
- **工作区**：右侧面板列出对话工作区的文件和只读的 Skills，可预览、下载、删除。
- **来源**：来自飞书的对话在标题旁标注来源；事件（定时任务、Webhook、子任务报告、渠道消息）显示为事件卡片。

## 插件与 Skill

- **内置插件**：默认开启；需要配置而未配置的显示原因且不生效。详情里有设置表单（密钥只写不读）和逐个工具的开关。
- **MCP 服务器**：填名称、Streamable HTTP 地址和可选请求头即可添加；显示连接状态，支持重新连接、OAuth 登录、编辑和移除。带界面的工具标注“带界面”。
- **Skills**：从 Git 仓库（可指定分支和子目录）或 zip 安装，兼容 Agent Skills 格式；可开关、查看文件、卸载。服务器不能解压或拉取时禁用安装并说明原因。

## 渠道

- 连接设置由服务器声明（App ID、App Secret、平台、流式卡片、群聊上下文条数、人设）。
- 配对：生成十分钟内有效的一次性配对码，私聊发给机器人（`/pair <码>`）。
- 允许名单：所有者和被允许的人；其他人的消息被拒绝并出现在“最近的消息”里，可以在那里“允许此人”。

## 设置

- **个性化**：称呼和自定义指令，对网页和渠道里的所有对话生效。
- **模型**：用 API Key 或订阅账号登录模型服务（服务器执行登录流程，页面显示它的提示并回答它的问题）；列出可用模型。
- **外观**：跟随系统 / 浅色 / 深色，按浏览器保存。
- **账户**：修改密码（其他设备随即退出）、退出登录。

## 质量要求（roadmap-5 N40–N45）

| 编号 | 要求 |
|---|---|
| N40 | 颜色、间距、圆角、字号只来自 `src/styles/app.css` 的 token；浅色和深色都完整 |
| N41 | 390px 宽可用：侧栏是抽屉，面板全屏，页面没有横向滚动 |
| N42 | 流式输出不抖动；上滚后不自动跟随 |
| N43 | 每个页面和列表都有空、加载、出错三种状态；断线时提示并自动重连 |
| N44 | 菜单、对话框、下拉都可用键盘操作（Radix）；`⌘K` 命令面板 |
| N45 | 路径路由，刷新后停在原处 |

## 代码结构

```text
packages/web/src
├─ app/        外壳、登录、客户端（WebSocket 状态与请求）
├─ features/   chat、plugins、automations、channels、settings
├─ plugins/    工具结果的视图：artifact、email、image、ui（生成式 UI）
├─ ui/         基础组件（Radix + Tailwind v4）
├─ lib/        路由、socket、轮次模型、格式化、主题
└─ styles/     设计 token 与全局样式
```

`npm run genui -w @gense/web` 从 `src/plugins/ui/genui` 生成服务器使用的组件说明（`packages/server/src/plugins/genui/generated.ts`）；`npm run check` 会校验它没有过期。
