# Spec：网页界面

状态：2026-11-14 随界面重新设计（`feat/ui-redesign`）更新，描述 `packages/web` 的当前实现。2026-11-10 的 roadmap-5 版本曾把项目和记忆列为“不做”；它们以“预览”功能回到界面后，roadmap-7 阶段 A 把它们接到了服务器。

网页是每个用户的工作台，产品名在界面上写作 **Gense**：对话、项目、资料库、收件箱、记忆、给助手接工具（插件、MCP、Skills）、自动化和飞书渠道。它只通过 `@gense/protocol` 和服务器通信：一条 WebSocket（`/ws`）承载全部状态和请求，登录和改密码走 `/api/*`。

## 信息架构

| 路径 | 页面 | 内容 |
|---|---|---|
| `/` | 首页 | 按时段问候、输入框、分类的起始提示、“继续上次的”卡片、收件箱未读提示；发送后创建对话并跳转 |
| `/c/:treeId` | 对话 | 轮次、版本、顺便问、工具步骤、界面（生成式 UI / MCP Apps / Artifact）、工作区文件 |
| `/inbox` | 收件箱 | 定时任务的结果和渠道进来的对话，以及完成或失败的数据导出，按时间排列；已读状态存在服务器（`inbox.read`），网页按它算未读数 |
| `/projects`、`/projects/:id` | 项目 | 一组对话、一份项目指令和一组项目文件；指令和文件清单进入项目里每个对话的系统提示词，文件在沙箱里只读挂载 |
| `/library` | 资料库 | 所有对话工作区和项目里的文件，由服务器分页（`library.list`），按类型筛选、按文件名搜索、下载 |
| `/memory` | 记忆 | 记忆条目的增删改、开关、生效范围（全部对话或某个项目）和搜索；“参考记忆”和“只记我明确要求的”两个开关 |
| `/plugins`、`/plugins/skills` | 插件与 Skill | 内置插件、MCP 服务器；Agent Skills 的安装、开关和查看 |
| `/automations` | 自动化 | 定时任务、Webhook |
| `/channels` | 渠道 | 飞书连接设置、配对、允许名单、最近收到的消息 |
| `/s/:token` | 公开分享页 | 不需要登录、不连 WebSocket；只读显示分享时的快照：问题、回答、生成式界面、生成的图片和来源（roadmap-7 B2） |
| `/settings/:section` | 设置 | 个性化、模型、外观、快捷键、数据、用量、账户 |

- 路径路由；服务器对未知路径返回 `index.html`，刷新或分享链接停在原处。
- 侧栏：新对话、搜索（`⌘K` / `Ctrl+K` 命令面板）、工作入口（收件箱、项目、资料库）、可折叠的“智能体”分组（记忆、插件与 Skill、自动化、渠道）、置顶和按日期分组的对话、账户菜单。桌面上可收成 56px 的图标栏（`⌘B`），手机上是抽屉。
- 未登录时只显示登录页（桌面是左右分栏）；会话失效（例如在别处改了密码）时回到登录页。

## 设计语言

- **石色外框 + 白色画布**：侧栏和窗口底色用 `bg-sidebar`，主区域是带圆角和 `shadow-canvas` 的内嵌卡片。
- **强调色可选**：青玉（默认）、海蓝、堇紫、赤陶、绯红、墨色，写在 `<html data-accent>` 上；主题写在 `data-theme` 上。两者都按浏览器保存。
- 标题用无衬线、紧字距；不再使用衬线字体。卡片圆角 `rounded-2xl`，列表用“圆角外框 + 分隔线”。
- 页面骨架统一用 `Page`（`app/Shell.tsx`）；设置项统一用“左说明、右控件”的行。

### 浏览器里的数据

只有草稿和这台设备的显示偏好（发送键、宽版布局、主题、强调色）留在浏览器（`lib/lab.ts`、`lib/theme.ts`，localStorage 键以 `gense.` 开头）。其余都在账户里，所有设备一致。

早先存在浏览器里的项目和记忆，在登录后自动导入账户一次（`app/importLocal.ts`），然后从浏览器删除。


## 对话页

- **轮次**：用户消息靠右，可编辑（产生一个新版本）和复制；回答靠左，可复制、👍 / 👎（👎 可选原因和补充说明，存到服务器，`feedback.set`）、朗读（服务器有语音时用 `/api/speech/tts`，否则用浏览器的语音）、重新生成（同样产生新版本）；“更多”里有存入记忆（存入账户，可撤销）。模型用 `memory` 工具新增、修改或删除记忆时，回答里显示一条“已记住 / 已更新记忆 / 已忘掉”，带撤销。最新的回答下面给出服务器生成的追问建议（`suggestions` 消息，偏好 `suggestions` 关掉后不生成）。同一位置有多个版本时显示 `‹ 2/3 ›` 切换。DeepSeek 安全检查拦下的提问显示为“这个问题我没法回答”的卡片，不显示正文。
- **步骤**：思考和工具调用折叠成一行摘要（“3 次工具调用 · 1 次失败”），展开看参数和结果。DeepSeek App 模型自己联网时，它的搜索、读网页等步骤（运行中来自 `native` 消息，结束后来自对话里的 `app.native` 记录）和工具调用排在一起，摘要写成“搜索 N 次 · 阅读 M 个网页”；引用的网页进入回答的来源。带界面的工具结果直接显示在正文里。
- **界面**：生成式 UI（`ui_render`，OpenUI 程序）、Artifact 卡片和 MCP Apps 都渲染在同一个槽位。MCP Apps 运行在只允许脚本和表单的沙箱 iframe 中，带注入的 CSP，通过 postMessage 上的 JSON-RPC 和宿主通信；可以展开到右侧面板（手机上全屏）。
- **流式**：只有读者停在底部时才跟随新内容；上滚后停止跟随并出现“回到底部”。
- **版本，没有分支树**：编辑和重新生成都在原消息旁边加一个版本，用 `‹ 2/3 ›` 切换，切到哪个版本就从那里继续。界面里没有分叉、分支图或“总结给主线”；子代理在服务器内部运行，结果以事件回到对话，界面不提供打开子代理分支的入口。
- **顺便问**（`/顺便问`，btw）：基于当前显示的版本快速问一句。问题和回答显示在输入框上方的卡片里，答案流式出现；关闭卡片会丢掉回答，还在生成时会先停止。回答不写进对话，后续回复看不到它；这次调用不带工具，只把对话的文字（不含工具调用）交给模型，用的是当前选择的模型。回复进行中也可以问（协议 `btw` / `btw.cancel`，服务器推送 `btw` 消息）。
- **输入框**：“＋”菜单（上传、`@`、`/`、浏览资料库）、“工具”菜单（深度研究、联网搜索等）、附件（单个不超过 20 MB，可拖入；服务器提取了文字或做了 OCR 的附件在用户消息里标“已解析 / 已识别 N 页”）、模型和推理强度选择、语音听写（服务器有语音时录音后发到 `/api/speech/asr`，最长 2 分钟，识别期间按钮转圈；否则用浏览器的语音识别）、发送 / 停止。没发出去的文字按对话保存为草稿，发送后清除。模型选择按浏览器记住。
- **标题栏**：标题菜单（重命名、置顶、移到项目、导出 Markdown、压缩上下文、删除）、分享对话框；宽屏右侧有轮次大纲。
- **分享**：对话框里可以复制或下载 Markdown，或创建公开链接。链接是创建那一刻的快照，由网页端按当前分支构造（`features/share/snapshot.ts`，不含思考、工具参数、工作区文件和 MCP Apps；图片内联），之后可“更新为最新内容”（链接不变）或“停止分享”。全部链接列在设置 → 数据。
- **临时对话**：首页右上角的开关。临时对话不进侧栏、搜索、首页“继续”、资料库和命令面板，不能分享、置顶或移到项目；页面顶部一直有提示。在应用里离开它时网页端删除它；刷新不算离开，服务器在 24 小时后删除剩下的。
- **工作区**：右侧面板列出对话工作区的文件和只读的 Skills，可预览、下载、删除；图片直接显示，PDF 逐页渲染（pdf.js，按需加载）。
- **嵌入与引用工作区文件**：回答里用工作区路径写 Markdown 图片或链接。`![发票](attachments/a.png)` 和 `![第 3 页](attachments/r.pdf#page=3)` 在正文里显示图片或那一页 PDF，带说明文字；`[合同第 3 页](attachments/c.pdf#page=3)` 显示为一个文件标签。点击都会在右侧面板打开文件，PDF 跳到并高亮那一页。分享页里没有工作区，这些引用只显示为文字。飞书卡片里嵌入写成“（图：说明）”，文件本身作为附件另发。
- **数学**：remark-math + KaTeX（含 mhchem 和常见的 physics、siunitx 宏）。渲染前 `lib/math.ts` 统一模型的写法：`\(…\)`、`\[…\]`、行内的 `$$…$$`、裸 `\begin{equation}` 等都能显示；价格里的单个 `$` 保持原样；表格里公式中的 `|` 不再拆单元格。选中公式复制得到 `$…$` 源码（KaTeX copy-tex）。
- **来源**：来自飞书的对话在标题旁标注来源；事件（定时任务、Webhook、子任务报告、渠道消息）显示为事件卡片。

## 插件与 Skill

- **内置插件**：默认开启；需要配置而未配置的显示原因且不生效。详情里有设置表单（密钥只写不读）和逐个工具的开关。
- **MCP 服务器**：填名称、Streamable HTTP 地址和可选请求头即可添加；显示连接状态，支持重新连接、OAuth 登录、编辑和移除。带界面的工具标注“带界面”。
- **Skills**：从 Git 仓库（可指定分支和子目录）或 zip 安装，兼容 Agent Skills 格式；可开关、查看文件、卸载。服务器不能解压或拉取时禁用安装并说明原因。

## 渠道

- 连接设置由服务器声明（App ID、App Secret、平台、流式卡片、群聊上下文条数、人设）。
- 配对：生成十分钟内有效的一次性配对码，私聊发给机器人（`/pair <码>`）。
- 允许名单：所有者和被允许的人；其他人的消息被拒绝并出现在“最近的消息”里，可以在那里“允许此人”。

## 设置

- **个性化**：称呼和自定义指令，对网页和渠道里的所有对话生效。
- **模型**：用 API Key 或订阅账号登录模型服务（服务器执行登录流程，页面显示它的提示并回答它的问题）；列出可用模型，按服务分组，每个模型一个开关，每个服务有“全部打开 / 全部关闭”。关掉的模型不出现在输入框的模型菜单里，也不会被选为默认模型（偏好 `hiddenModels`，`provider:id` 列表，账户级，所以换设备也一样；只记关掉的，新登录的服务和新出的模型默认打开）。关掉不等于禁用：已经用它的对话照样继续，开关随时可以打开。正在用的模型被关掉时改用默认模型；全部关掉时模型菜单提示去设置打开。自己登录的 DeepSeek 有“安全检查”开关（偏好 `deepseekSafety`，默认开）。
- **外观**：主题（跟随系统 / 浅色 / 深色）、强调色、宽版布局按浏览器保存；追问建议是账户偏好。
- **快捷键**：发送键（Enter 或 `⌘/Ctrl+Enter`）和全部快捷键的列表。
- **数据**：记忆开关（账户级，飞书里的对话同样生效）、导出全部数据（服务器打包 zip，`export.create`，最多保留 3 份，完成后进收件箱，`/api/exports/:id` 下载）、公开链接列表（打开、停止分享）、导出或清除这个浏览器里的数据（草稿、界面偏好）。
- **用量**：当前方案和对话、定时任务、模型的数量；用量明细来自 `/api/usage`（`UsageReport`：模型 token 按天或模型分组，搜索和读网页次数算在模型行里；另列 OCR、听写、朗读的服务用量），和管理后台的用量页共用 `features/usage/UsageReport.tsx`。
- **账户**：修改密码（其他设备随即退出）、退出登录。

## 管理后台

- **共享模型服务**：类型二选一，DeepSeek（新建时的默认）或 OpenAI 兼容。DeepSeek 的地址和模型列表可留空，用官方地址和它当前的全部模型；安全检查始终开启。卡片上标注 DeepSeek、能自己联网的 App 模型标“原生联网”。
- **用量**：全部用户的 `UsageReport`（`/api/admin/usage`），可按用户分组。

## 质量要求（roadmap-5 N40–N45）

| 编号 | 要求 |
|---|---|
| N40 | 颜色、间距、圆角、字号只来自 `src/styles/app.css` 的 token；浅色和深色都完整 |
| N41 | 390px 宽可用：侧栏是抽屉，面板全屏，页面没有横向滚动 |
| N42 | 流式输出不抖动；上滚后不自动跟随 |
| N43 | 每个页面和列表都有空、加载、出错三种状态；断线时提示并自动重连 |
| N44 | 菜单、对话框、下拉都可用键盘操作（Radix）；`⌘K` 命令面板 |
| N45 | 路径路由，刷新后停在原处 |

## 代码结构

```text
packages/web/src
├─ app/        外壳、登录、客户端（WebSocket 状态与请求）
├─ features/   chat、inbox、projects、library、memory、plugins、automations、channels、settings、admin
├─ plugins/    工具结果的视图：artifact、email、image、ui（生成式 UI）
├─ ui/         基础组件（Radix + Tailwind v4）
├─ lib/        路由、socket、轮次模型、格式化、主题、lab（草稿和设备偏好）
└─ styles/     设计 token 与全局样式
```

`npm run genui -w @gense/web` 从 `src/plugins/ui/genui` 生成服务器使用的组件说明（`packages/server/src/plugins/genui/generated.ts`）；`npm run check` 会校验它没有过期。
