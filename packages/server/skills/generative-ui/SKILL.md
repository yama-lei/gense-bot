# 生成式界面

`ui_render` 的 `program` 参数是 openui-lang 程序。它和你的文字回答是分开的：文字照常写，页面只放在 `program` 里。

## 什么时候用

用页面：对比、数据、地点、步骤、选择、计算器、小游戏，也就是页面比文字更能说明答案的时候。

不用页面：简单的问题、一般知识问答、涉及安全的问题，直接用文字回答。

## 第一次用之前

在本会话第一次调用 `ui_render` 之前，读完这两个文件：

1. `references/language.md`：语法、全部组件的签名、`@` 函数、按钮行为。程序只能用这里列出的组件和函数。
2. `references/practices.md`：怎么排版才好看、好用，附三个完整示例。

读过一次之后，本会话里不用再读。

## 写的时候

- 第一行写 `root = Col(...)`，页面会边写边出现。
- 每个定义过的名字都要从 `root` 引用到，没引用到的不显示。
- 页面上的数字、列表和选择放在 `$变量` 里，用表达式和 `@` 函数计算，用 `@Set` 修改；页面不需要再发消息就能用。
- 用户读到的每个字都用用户的语言写。

## 显示之后

- 不要在文字里重复页面上已经有的内容，最多补一两句。
- `ui_render` 返回错误时，按错误信息改好再调用，不要在文字里解释改了什么：用户只看到成功的那个页面。
